# 📌 Timeline do Projeto Northwind StartDev Labs

## 🎯 Objetivo do Projeto

Projeto desenvolvido com o objetivo de praticar Engenharia de Dados, manipulação de dados, SQL e construção de pipelines utilizando uma base realista de negócio.

O projeto utiliza a base Northwind para simular um ambiente de análise e transformação de dados.

---

# 🚀 Início do Projeto

## Data:
Julho/2026

## Etapas realizadas:

- Configuração do ambiente WSL2;
- Instalação e configuração do Python;
- Criação de ambiente virtual (.venv);
- Organização inicial do projeto;
- Configuração do Git e GitHub.
